翻转校园跑自动刷 · 黄河科技学院特供

本工具完全免费并在 GitHub 开源，禁止倒卖；如您是付费获取，请联系卖家退款。

一、前提条件
1. Windows 10 / 11 电脑。
2. 微信 4.x（数据目录是 Tencent\xwechat，不是旧版 WeChat Files）。
3. 微信已登录，并且打开过一次“翻转任务跑”小程序，让本地生成登录 Token。
4. 本包已内置学校路线，直接使用；其他学校不适用。

二、安装（每台电脑做一次）

如果你下载的是 Release 里的 fanzhuan-campus-run-setup.zip：
1. 解压。
2. 右键 fanzhuan-campus-run-setup.exe，选择“以管理员身份运行”。
3. 看到“安装完成”后，桌面会出现“翻转校园跑自动刷”快捷方式。

如果你拿到的是源码或便携包：
1. 把“翻转校园跑自动刷”整个文件夹解压到电脑上。
2. 右键“安装.bat”，选择“以管理员身份运行”。
3. 看到“安装完成”后，桌面会出现“翻转校园跑自动刷”快捷方式。

安装目录：%LOCALAPPDATA%\FanzhuanAutoRun

三、使用
- 自动运行：每天 07:10、18:10 各一次，每次约 25–33 分钟（每趟路程随机 2.7–4.4 公里）。
- 手动运行：双击桌面的“翻转校园跑自动刷”。
- 如果双击没反应：先运行“安装.bat”，再双击桌面快捷方式；不要在压缩包里直接运行。
- 运行日志：安装目录下的 campus_auto_run.log。
- 自动运行时电脑需要开机，微信保持登录；锁屏不影响。

四、路线是随机的
- 每趟开始前现生成一条新路线：起点位置、跑的方向、折返点、路的左右侧全部随机，
  所以每次上传的轨迹都不一样，不会出现“每次都是同一条线”的情况。
- 配速固定不变，约 7 分 30 秒一公里，和真跑一样。
- 每趟都会把校园主路完整走一遍，保证打卡点不遗漏。
- 想先看这一趟会跑成什么样（不联网、不上传）：
  在安装目录按住 Shift 右键“在此处打开 PowerShell 窗口”，执行
  runtime\node.exe campus_auto_run.js --preview 3
  会打印 3 条随机路线的路程/配速，并生成 last_route.json。

五、注意事项
- 每天最多计 2 次有效跑步，单次至少 2.5 km，有效时段 06:00–23:00。
- 自动跑期间不要在小程序或手机上手动开始跑步，否则会提示“已有进行中的跑步”并跳过。
- 如果提示“未找到登录 Token”，打开一次微信里的“翻转任务跑”小程序再运行。
- 如果提示登录失效，同样打开一次小程序刷新登录状态。
- 每个账号的 Token 只从本机微信本地读取，不会上传；不要把安装目录发给别人。
- 本项目仅供学习交流，请遵守学校相关规定。

六、卸载
双击“卸载.bat”，会删除计划任务、桌面快捷方式和安装目录。

七、说明
本工具为黄河科技学院特供，路线基于本校真实轨迹随机生成。其他学校的小程序接口和打卡点不同，请使用 GitHub 上的虚拟定位方案。
