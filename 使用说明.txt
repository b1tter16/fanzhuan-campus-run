翻转校园跑自动刷 · 黄河科技学院特供

本工具完全免费并在 GitHub 开源，禁止倒卖；如您是付费获取，请联系卖家退款。

一、前提条件
1. Windows 10 / 11 电脑。
2. 微信 4.x（数据目录是 Tencent\xwechat，不是旧版 WeChat Files）。
3. 微信已登录，并且打开过一次“翻转任务跑”小程序，让本地生成登录 Token。
4. 本包已内置学校路线，直接使用；其他学校不适用。

二、安装（每台电脑做一次）
1. 把“翻转校园跑自动刷”整个文件夹解压到电脑上，不要只复制其中的 exe。
2. 右键“安装.bat”，选择“以管理员身份运行”。
3. 看到“安装完成”后，桌面会出现“翻转校园跑自动刷”快捷方式。
4. 安装目录：%LOCALAPPDATA%\FanzhuanAutoRun

三、使用
- 自动运行：每天 07:10、18:10 各一次，每次约 20 分钟。
- 手动运行：双击桌面的“翻转校园跑自动刷”。
- 如果双击没反应：先运行“安装.bat”，再双击桌面快捷方式；不要在压缩包里直接运行。
- 运行日志：安装目录下的 campus_auto_run.log。
- 自动运行时电脑需要开机，微信保持登录；锁屏不影响。

四、注意事项
- 每天最多计 2 次有效跑步，单次至少 2.5 km，有效时段 06:00–23:00。
- 自动跑期间不要在小程序或手机上手动开始跑步，否则会提示“已有进行中的跑步”并跳过。
- 如果提示“未找到登录 Token”，打开一次微信里的“翻转任务跑”小程序再运行。
- 如果提示登录失效，同样打开一次小程序刷新登录状态。
- 每个账号的 Token 只从本机微信本地读取，不会上传；不要把安装目录发给别人。
- 本项目仅供学习交流，请遵守学校相关规定。

五、卸载
双击“卸载.bat”，会删除计划任务、桌面快捷方式和安装目录。

六、说明
本工具为黄河科技学院特供，路线已固定。其他学校的小程序接口和打卡点不同，请使用 GitHub 上的虚拟定位方案。
