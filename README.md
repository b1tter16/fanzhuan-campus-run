# 翻转校园跑自动刷（黄河科技学院特供）

本工具为黄河科技学院特供。其他学校的小程序接口和打卡点不同，请使用 GitHub 上的虚拟定位方案。

> 本工具完全免费并在 GitHub 开源，禁止倒卖；如您是付费获取，请联系卖家退款。

## 项目说明

通过读取本机微信小程序 `翻转任务跑` 的本地登录 Token，直接调用其跑步接口，按固定时间间隔回放一条轨迹，实现校园跑的自动记录。

- 不修改小程序客户端
- 不依赖电脑版微信的定位权限
- Token 只从本机微信本地存储读取
- 每条记录按真实时间间隔上传轨迹点

## 目录结构

```text
campus_auto_run.js       主程序
token_reader.js          读取本机微信小程序 Token
reference_run_safe.json  内置学校路线（仅经纬度）
一键校园跑.cmd            手动启动
安装.bat                 安装计划任务和桌面快捷方式
卸载.bat                 卸载
setup_task.ps1           安装脚本
run_campus_hidden.vbs    计划任务静默启动
使用说明.txt             使用说明
```

## 使用（推荐：Release 安装包）

1. 打开右侧 `Releases`，下载 `fanzhuan-campus-run-setup.zip`。
2. 解压后，右键 `fanzhuan-campus-run-setup.exe`，选择“以管理员身份运行”。
3. 安装前先登录微信，并打开一次 `翻转任务跑` 小程序。
4. 安装完成后，双击桌面的 `翻转校园跑自动刷` 手动运行，或等待每天 07:10 / 18:10 自动运行。

这个方式不需要安装 Node.js，安装包已经内置运行环境。

## 从源码运行

1. 安装 Node.js 18+。
2. 运行 `安装.bat`。
3. 双击桌面的 `翻转校园跑自动刷`。

详细步骤见 `使用说明.txt`。

## 轨迹文件

`reference_run_safe.json` 只保存经纬度轨迹点，已内置学校路线。

## 限制

- 每天最多计 2 次有效跑步
- 单次至少 2.5 km
- 有效时段 06:00–23:00
- Token 过期后需要重新打开小程序
