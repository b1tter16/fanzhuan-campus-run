# 翻转校园跑自动刷（黄河科技学院特供）

本工具为黄河科技学院特供。其他学校的小程序接口和打卡点不同，请使用 GitHub 上的虚拟定位方案。

> 本工具完全免费并在 GitHub 开源，禁止倒卖；如您是付费获取，请联系卖家退款。

## 项目说明

通过读取本机微信小程序 `翻转任务跑` 的本地登录 Token，直接调用其跑步接口，按真实时间间隔上传轨迹点，实现校园跑的自动记录。

- 不修改小程序客户端
- 不依赖电脑版微信的定位权限
- Token 只从本机微信本地存储读取
- 每条记录按真实时间间隔上传轨迹点
- **路线每趟随机生成，配速固定**

## 随机路线

`reference_run_safe.json` 只保存经纬度，是本校真实跑过的一条轨迹，被当作「校园主路骨架」。

`route_gen.js` 每趟都基于这条主路现生成一条新路线：

- 起点在主路上随机取（0 ~ 全程）
- 先朝较近的一端跑一段，在那里折返
- 顺向把整条主路跑完（保证打卡点全覆盖）
- 再按 0 ~ 700 m 的随机剩余路程继续
- 全程叠加左右偏移（跑在路的哪一侧随机）与 GPS 抖动

配速固定：每个点间隔 5 秒、步长 11.07 m，约 7 分 30 秒一公里。
每趟路程 2.7–4.4 km（原来固定 2.66 km），平均约 3.5 km。

离线预览本次路线（不联网、不上传）：

```text
runtime\node.exe campus_auto_run.js --preview 3
```

## 使用（推荐：Release 安装包）

1. 打开右侧 `Releases`，下载 `fanzhuan-campus-run-setup.zip`。
2. 解压后，右键 `fanzhuan-campus-run-setup.exe`，选择“以管理员身份运行”。
3. 安装前先登录微信，并打开一次 `翻转任务跑` 小程序。
4. 安装完成后，双击桌面的 `翻转校园跑自动刷` 手动运行，或等待每天 07:10 / 18:10 自动运行。

这个方式**不需要安装 Node.js**，安装包已经内置运行环境。

## 从源码运行

1. 安装 Node.js 18+。
2. 运行 `安装.bat`。
3. 双击桌面的 `翻转校园跑自动刷`。

详细步骤见 `使用说明.txt`。

## 限制

- 每天最多计 2 次有效跑步
- 单次至少 2.5 km
- 有效时段 06:00–23:00
- Token 过期后需要重新打开小程序
